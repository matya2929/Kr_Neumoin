# src/data

Этот каталог зарезервирован для **клиентских** статических данных, которые
не имитируют запросы к серверу (например, словари, локальные настройки UI,
пресеты темы). Боевые данные арсенала и врагов живут в `backend/data/*.json`
и обслуживаются через `backend/services/*.js`.

В демо-версии вся информация загружается через `src/services/api.js`,
который проксирует вызовы в mock backend.
